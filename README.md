# ♻️ Smart Waste Classifier

An AI-powered Computer Vision project that identifies different types of waste from images and provides a confidence score and disposal recommendation.

## 📌 About the Project

Smart Waste Classifier is a student-focused Machine Learning and Computer Vision project designed to automatically classify waste from an uploaded image.

The planned workflow is:

**Image Upload / Camera → Image Preprocessing → AI Model → Waste Classification → Confidence Score → Disposal Recommendation**

This project is intended to demonstrate the complete ML/CV pipeline, from dataset preparation and model training to web-based prediction.

## ✨ Features

- 📷 Image upload
- 🤖 AI-based waste classification
- 📊 Confidence score
- 📸 Camera mode
- ♻️ Waste disposal recommendations
- 🗂️ Prediction history
