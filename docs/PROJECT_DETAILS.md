# Project Details

## Project Name
Smart Waste Classifier

## Project Type
Machine Learning + Computer Vision + Web Application

## Problem Statement
Manual waste segregation can be difficult and inconsistent. This project explores how computer vision can assist users in identifying common waste categories from images.

## Proposed Solution
The application accepts an image or camera capture, processes it through an image-classification model, predicts the waste category, and displays the prediction with a confidence score and disposal guidance.

## Learning Outcomes
- Understand image datasets and preprocessing
- Train and evaluate an image classification model
- Use transfer learning for computer vision
- Build a Flask backend for ML inference
- Connect a web interface to an ML model
- Store prediction history using SQLite
- Document an end-to-end AI project

## Current Status
The project is being developed incrementally. Repository documentation describes the intended architecture and planned features; implementation will be added and tested step-by-step.
